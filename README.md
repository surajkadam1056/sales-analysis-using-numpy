# Sales Analysis Using NumPy

A practical sales analysis project built using **Python and NumPy** to analyze product-wise and month-wise sales data and answer basic business questions.

## Project Overview

This project focuses on applying NumPy concepts to a small sales dataset. The analysis includes sales aggregation, statistical analysis, filtering, maximum/minimum value analysis, and sales forecasting using a 10% growth assumption.

## Objectives

* Analyze product-wise and month-wise sales
* Calculate total and average sales
* Identify highest and lowest sales values
* Apply Boolean filtering to sales data
* Use NumPy broadcasting for expected sales calculation
* Answer basic business-oriented questions using NumPy

## Dataset

The dataset contains sales values for four products across six months:

* Laptop
* Mobile
* Headphones
* Tablet

Months covered:

* January
* February
* March
* April
* May
* June

## Key Analysis

The project answers questions such as:

* Which product has the highest total sales?
* Which month has the highest total sales?
* What is the overall average sales?
* How many sales values are greater than 200?
* What are the expected sales after assuming 10% growth?
